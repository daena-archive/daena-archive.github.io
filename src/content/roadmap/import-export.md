Markdown, plain text, HTML, DOCX, folders, ZIP, Obsidian vaults, and MediaWiki XML already import through the review pipeline, and enabled plugin importers use that same pipeline. Reader-facing export, and any format the import guide does not list, is still planned. A format is not advertised as supported until its bounded workflow is released.
