## Make the studio your own

Daena uses the same manifest and broker concepts for bundled modules and optional plugins. Extensions can add meaning to shared records without receiving a database handle or unrestricted host access.

## Permissions stay explicit

Capabilities are declared by the package and granted by the user. Sessions are bound to the installed package, project, version, and current activation. Disabling, upgrading, uninstalling, or closing a project revokes access.

## Portable data remains yours

When a plugin is disabled, its UI contributions disappear while its portable interpretation state remains available for recovery and export.
