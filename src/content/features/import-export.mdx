## Portability without pretending every format is equivalent

Daena's own portable checkpoint is designed for reconstruction. Reader-facing exports and third-party imports solve different problems, so they remain explicit workflows rather than silent background conversion.

## Planned in bounded slices

Markdown export and external import systems are being designed incrementally. Supported formats will appear here and in the documentation only after the implementation is available.
