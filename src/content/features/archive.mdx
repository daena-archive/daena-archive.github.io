## Your world belongs to you

Daena's local database makes day-to-day work fast. Deterministic Markdown, JSON, and native assets provide a portable checkpoint around that runtime. Derived indexes can be rebuilt without becoming a second source of authored truth.

## Honest recovery boundaries

Portable files are a clean reconstruction point only after Daena has completed a checkpoint. If a checkpoint is pending or failed, newer committed work may still exist in the local runtime and must not be discarded.

## No account required

The core studio is designed for local use. Network access is reserved for choices such as remote AI providers, Git remotes, downloads, or external integrations.
