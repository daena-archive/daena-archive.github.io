## Help when you ask for it

AI is a tool inside Daena, not the product's identity. It can assist with rewriting, expansion, and context-aware suggestions when useful, then step away.

## Local and remote follow one workflow

Local and remote providers appear through the same active-provider experience. The application derives security requirements from the configured endpoint while keeping network and credential boundaries internal.

## Proposals, not authority

Generated text does not silently mutate the archive. You decide what to accept, and accepted changes pass through the same revision-aware storage path as any other edit.
