## Your project has a history too

World history belongs in Timeline. Project history belongs here. Daena flushes a portable checkpoint, validates it, and shows the exact staging set before an explicit commit.

## User-controlled actions

Commits, resets, remote changes, and recovery operations are never ambient background behavior. Destructive or external actions remain visible choices in the trusted application shell.

## Runtime data stays local

Daena's machine-local database, indexes, locks, and recovery material are not included by the built-in Git workflow.
