AI is disabled unless you configure and activate a provider. Local endpoints such as LM Studio or Ollama and remote endpoints share the same active-provider workflow; Daena derives the security boundary from the endpoint.

Remote credentials remain machine-local. Generated text appears as a proposal and does not become project data until you accept it.
