---
title: Linking lore to maps
description: Connect shared records to geography without duplicating them.
sidebar:
  order: 2
---

Select an existing entity when capturing a location, or create the shared record first and return to the map. The resulting link points to the entity's stable identity rather than copying its title into provider data.

Enabled modules can consume Maps' versioned navigation service. If Maps is disabled, its navigation contributions disappear while portable map interpretation data remains available.
