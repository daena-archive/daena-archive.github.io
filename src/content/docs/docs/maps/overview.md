Maps is a beta workspace. It supports native physical-world work and Fantasy Map Generator integrations, with editing and generation capabilities at different maturity levels.

Map records use the same stable identity as other entities. Provider files remain opaque assets; Daena-owned locations, roles, dates, and relationships remain in the shared project model.
