Choose a contributed template — Person, Place, Artifact, Faction, Culture, or Concept — then give the record a name. These six templates come from the Lore module; additional types may appear when other modules or custom schema are enabled.

Write freely in the record's document and add structured fields only where they provide lasting value. Attach images and files to the owning entity rather than scattering path references through prose.

## A simple workflow

1. **Create with New.** The Lore header defaults to a Lore template; the global New action opens the full template gallery instead.
2. **Name, then write.** Only the name is required. A few sentences today beat an empty perfect template.
3. **Connect context with relationships.** Link the people, places, and ideas that give the entry meaning. Relationship groups are organized by defining module and stay visible from both sides.
4. **Archive instead of deleting.** Everyday menus offer Archive, which is reversible. Permanent deletion lives in Project Center → Archive only.

## Lifecycle and status

Every collection row offers Open, Edit identity, and Archive. Renaming or changing type through Edit identity refreshes Library, Wiki, Graph, Timeline labels, and Tree labels without changing the entity ID.

While saving, the editor reports Saving…, Saved, a revision conflict with reload and retry options, or a failure with retry — never a silent overwrite. If another view changed the same record, keep your draft and choose Reload current values, Review draft, or Reapply draft onto current when safe.
