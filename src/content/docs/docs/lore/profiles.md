A Profile is optional structured detail on a Lore entity. Any Lore entity can have one. It is not limited to people, and it is not a tabletop rules engine.

## Create a Profile

Create or delete a Profile from the entity. Start from a preset, or start from an empty custom Profile.

The picker suggests presets whose types include the current entity, always offers Custom, and groups the rest by genre. It shows a read-only component preview before you create the Profile. Create copies the preset. Later edits to the preset do not rewrite Profiles that were already created.

These bundled presets ship with Daena:

- D&D Character, D&D Faction, and D&D Location
- Fantasy Character, Fantasy Faction, Fantasy Kingdom, Fantasy Place, and Fantasy Artifact
- Sci-Fi Character, Sci-Fi Faction, Starship, and Colony / Station
- Custom, Culture, and Concept

Custom is the only universal preset. The preset manager edits name, description, icon, genre, entity types, and components.

## What a Profile holds

Values can be numeric, ranked, or boolean. A Profile can also hold traits, resources, basic derived values, and point allocation.

## Profiles over time

Timeline can record Profile changes, tie a change to an event, and show the Profile as it stood at a point in history.
