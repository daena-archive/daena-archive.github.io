Daena is a local-first desktop studio in active alpha development. This path introduces the current release without assuming a platform build that may not exist yet.

1. [Install Daena](./installing-daena/) from a currently published GitHub release.
2. [Create a project](./creating-a-project/) in a folder you control.
3. Build [your first connected world](./your-first-world/) from one place, one person, and one event.
4. Learn how enabled modules assemble [the workspace](./workspace/).

Keep a separate backup of important alpha projects and read release notes before upgrading.
