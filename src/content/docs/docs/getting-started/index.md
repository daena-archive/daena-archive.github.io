Daena is a local-first desktop studio in active beta development. There is no account, no subscription, and no required internet connection: each project lives in a folder on your computer.

This path takes you from a fresh install to a small connected world. It assumes the current beta release and nothing else.

## The path

1. [Install Daena](/docs/getting-started/installing-daena/) from a currently published GitHub release. Read the release notes first; beta builds may change the project format.
2. [Create a project](/docs/getting-started/creating-a-project/) in a folder you control. That folder is the boundary for everything you author.
3. Build [your first connected world](/docs/getting-started/your-first-world/) from one place, one person, and one event. This short exercise is the fastest way to understand Daena's shared world model.
4. Learn how enabled modules assemble [the workspace](/docs/getting-started/workspace/). Navigation, entity types, and views come from active modules rather than a fixed feature list.

## Before you begin

- Daena is **not production ready**. APIs, storage, and plugin contracts may change before `v1.0`.
- Keep a separate backup of any project you care about, and read the release notes before upgrading.
- Work through the pages in order the first time. Later, each guide stands on its own.

When you finish this path, continue with [Core Concepts](/docs/core-concepts/entities-and-concepts/) to understand how one stable record can appear in Lore, on a map, in history, and in a manuscript at the same time.
