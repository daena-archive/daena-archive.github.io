Daena is in active alpha development. Use the [latest GitHub release](https://github.com/daena-archive/daena/releases) as the authority for currently published operating-system builds, package formats, checksums, and known limitations.

## Before installing

- Read the release notes for migration or project-format notices.
- Keep a separate backup of any project you care about while Daena is alpha.
- Do not assume an installer exists for a platform merely because Tauri can target it.

After installation, continue with [Creating a project](../creating-a-project/).
