Start with one place, one person, and one event.

1. Create a place in Lore, such as **Eldermere**.
2. Create a person and relate them to the place.
3. Add an event in Timeline and select both records as context.
4. Open Writing Studio and reference the person from a short scene.

This small path exercises Daena's central idea: different modules contribute views and meaning, while the records remain part of one archive.
