The workspace is assembled from enabled modules. Navigation, entity types, views, and actions appear from those active contributions rather than a fixed list of hard-coded feature names.

Use global search to find shared records. Use module views to focus on a particular layer—Lore for connected reference, Timeline for history, Maps for place, Languages for conlang structure, and Writing Studio for documents.

Project settings contain storage, snapshots, remotes, plugins, and other project-level concerns.
