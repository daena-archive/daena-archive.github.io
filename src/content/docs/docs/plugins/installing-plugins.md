The third-party plugin platform remains experimental during Daena's alpha. Before installing a package, verify its source, version, supported Daena API range, license, and requested capabilities.

Enable or disable modules from the host-managed settings surface. Disabling a plugin revokes its sessions and removes its contributions without silently deleting portable project data.
